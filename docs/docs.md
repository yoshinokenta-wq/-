## **【スライド 4】 Cluctureの開発理由**

* **生徒側の課題**:  
  * 母国語と日本語の両方が話せて、面接指導ができる大人がいない（**支援不足**）  
  * 面接での独特の日本語表現や敬語、おじぎの角度等のマナーが理解しづらい（**練習不足**）  
* **先生側の課題**:  
  * 生徒の母国語への理解が不足し、翻訳アプリを活用した指導に労力がかかる（**負担感**）  
  * 生徒一人ひとりに多くの指導時間を割くことができない（**多忙感・時間的制約**）  
  * 生徒への指導が日本語となり、指導の意図が十分に伝わりづらい（**言葉の壁**）  
* **開発の狙い・解決策**:  
  * 翻訳アプリを活用することで、母国語での指導が受けられ、理解が向上する。  
  * 生徒は何度も好きなときに練習でき、教員は基礎練習を終えた生徒へ効率的に指導できる。  
  * 入試のために日本語を学ぶことで、外国籍生徒の日本語能力の飛躍的向上が期待できる。  
* **発表ノート（口頭原稿）**:  
  * この訪問をきっかけに、私たちは外国籍生徒支援のためにどんなことができるか議論し、まずは日本語能力の獲得が必要だと考えました。その中で、一番知識が増えるのは、「試験勉強するときだ。」とアイデアがでて、外国籍の生徒の「入試面接の練習不足」というキーワードから、高校入試面接練習アプリ「Clucture」を開発することにしました。「Clucture」を開発することで、生徒側、先生側のそれぞれの課題を解決することができます。  
  * まず生徒側ですが、第一に、母国語と日本語の両方を話せて、面接指導できる大人がいないという支援不足の問題、第二に、面接での独特の日本語の表現や敬語、おじぎの角度等のマナーが理解しづらいという練習不足の課題です。  
  * 次に先生側の課題ですが、生徒の母国語への理解が不足していたり、翻訳アプリを活用した指導に大きな労力がかかったりで、生徒一人一人に多くの指導時間を割くことができません。それに、生徒との使用言語の違いから、指導の意図が十分に伝わりづらい課題があります。  
  * そこで、Cluctureを使えば、生徒は何度でも好きな時に練習ができ、先生は基礎的な面接練習ができた生徒を指導できます。そして入試のために日本語を学ぶことで、外国籍生徒の日本語能力が極めて向上することが期待できます。

## **【スライド 5】 4つのモード紹介（アプリUI概要）**

* **アプリの主要4機能**:  
  1. **本番モード（日本語でのやり取りに慣れてきた方向け）**:  
     * 難易度を選んで5つの質問に回答。最後にアドバイスと採点結果を表示します。  
     * *UI画面要素*: 「本番モード hard」「学校生活を…」「母国と日本の文化の違いは」「アドバイスやヒント」「採点結果 60%」等。  
  2. **練習モード（日本語のやり取りに慣れていない方向け）**:  
     * 難易度を選んで一問一答で5つの質問に答え、それぞれにアドバイスを表示します。  
     * *UI画面要素*: 「練習モード hard」「御校の○○なところに魅力を感じ、志望しました」「素晴らしい答えですね！アドバイスとしては○○をしたほうがよりよくなりますよ！」等。  
  3. **単語帳モード**:  
     * 面接で頻出する語彙を学べる（例: 「御校（おんこう）」＝話し言葉、「貴校」＝書き言葉など）。  
  4. **行動並び替えモード**:  
     * 面接時の正しいマナーや立ち振る舞いをクイズ感覚で順番通りに並び替えて学ぶ。  
* **発表ノート（口頭原稿）**:  
  * 本アプリの機能をご紹介します。まず主要なモードが「本番モード」と「練習モード」になります。本番モードは、実際の面接を再現します。最後にアドバイスと評価が出力されます。練習モードは、一問一答形式で、その都度アドバイスを表示します。それから、単語帳モードでは、面接で頻出する単語。貴校や御校などの単語を学ぶことができます。最後に、行動並び替えモードは、面接時の正しいマナーや立ち振る舞いをクイズ感覚で身につけることができます。

## **【スライド 9】 本アプリの技術的特徴**

> 1. **Google Gemini Liveを使用した評価プロンプトの作成と翻訳機能の実装**:  
   * **評価軸（5観点・S〜Dの5段階評価）**: 「マナー・印象」「簡潔性・要約力」「論理的思考力」「対話力」「自己PR度・意欲」の観点から採点し、平均点と総合評価を出力。  
   * **プロンプト内判定基準（例: 簡潔性・要約力）**:  
     * **S (非常に優れている)**: 「〜です」と結論からハッキリ答え、理由や具体例も無駄なくまとまっている。  
     * **A (優れている)**: 質問に対する結論を最初に述べており、全体として整理されている。  
     * **B (標準)**: 結論から答えられているが、少し説明が長くなったり回りくどくなったりする。  
     * **C (要改善)**: 理由やエピソードから話し始めてしまい、結論が分かりにくい。  
     * **D (不十分)**: 質問の答えになっていない内容を長く話す、または極端に短すぎる。  
   * **多言語翻訳**: AIを活用した翻訳により多種多様な言語に対応可能。  
> 2. **Rubyを使ったWebアプリの実装**:  
   * Ruby言語を採用し、少ないコード量で素早く高性能なWebアプリを開発。  
* **発表ノート（口頭原稿）**:  
  * 次に、本アプリの技術的特徴です。一つ目はGoogle Gemini liveを使用した評価プロンプトの作成と翻訳機能の実装です。評価はマナー・印象、簡潔性・要約力、論理的思考力、対話力、自己PR度・意欲の五つの観点からS\~Dの五段階で評価し、最終的に平均点とそれに応じた五段階評価を表示します。翻訳機能もAIを活用する予定です。二つ目はRubyを使ったWebアプリの実装です。Rubyを使用することで、少ないコード量で素早く高性能なWebアプリを作成可能です。
